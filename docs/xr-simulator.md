# XR 시뮬레이터 조작법

Unity에서 Play를 누르고 Game 뷰를 클릭한 뒤 조작한다.

## 컨트롤러 입력

| 키보드 입력 | 실제 기기에서 대응하는 조작 | 현재 동작 |
| --- | --- | --- |
| Shift + I / K / J / L | 왼쪽 스틱을 앞 / 뒤 / 왼쪽 / 오른쪽으로 밀기 | 플레이어 이동. Shift + T를 함께 누르면 태블릿 항목 이동 |
| Shift + 1 | 왼쪽 컨트롤러 X 버튼 | 강조된 태블릿 버튼 선택 |
| Shift + 2 | 왼쪽 컨트롤러 Y 버튼 | 뒤로 가기 |
| Shift + T 유지 | 왼쪽 검지 트리거 | 누르는 동안 왼쪽 스틱을 태블릿 항목 이동·슬라이더 조절에 사용 |
| Shift + G | 왼쪽 손잡이 Grip 버튼 | 앱 종료. 에디터에서는 Play 종료 |
| I / K / J / L | 오른쪽 스틱을 앞 / 뒤 / 왼쪽 / 오른쪽으로 밀기 | 시점 상 / 하 / 좌 / 우 회전 |
| 1 / 2 | 오른쪽 컨트롤러 A / B 버튼 | 현재 위치에서 정면 방향 복원 / 레이저 켜기·끄기 |
| T | 오른쪽 검지 트리거 | 레이로 가리킨 버튼·이미지·픽셀 클릭 |
| G 유지 | 오른쪽 손잡이 Grip 버튼 | 누르는 동안 물체를 잡고 시선으로 이동. 놓으면 놓기 |
| Shift + 3 / 3 | 왼쪽 / 오른쪽 스틱 누르기 | 스틱 클릭 입력 |
| Shift + M | 왼쪽 컨트롤러 Menu 버튼(세 줄) | 태블릿 설정 열기·닫기 |

**Shift를 누르면 왼손, 누르지 않으면 오른손 버튼·스틱 입력이다.** 버튼 키를 먼저 놓고 Shift를 나중에 놓는다. 입력이 연결되어 있어도 해당 입력을 사용하는 기능이 없으면 화면에 변화가 없을 수 있다.

## 왼손으로 태블릿 조작

1. Game 뷰를 클릭하고 `Shift + T`를 누른 채 왼쪽 스틱을 중앙에 놓으면 태블릿 탐색을 시작한다. Trigger를 누른 동안 플레이어 이동은 차단된다.
2. `Shift + T`를 유지한 채 `I/K/J/L`로 항목을 고르고 `Shift + 1`로 선택한다. X는 Trigger를 놓은 상태에서도 선택할 수 있다. 힌트·이미지 확대·학습 정보·학습 단계·저장도 같은 방법으로 선택한다.
3. `Shift + M`으로 설정을 열거나 닫는다. 단계 이동을 선택하면 단계 이름 목록이 표시된다.
4. 밝기·볼륨 항목에서 `Shift + 1`로 조절 모드에 들어가면 테두리가 노란색으로 바뀐다. `Shift + T`를 누른 채 `J/L`로 값을 5%씩 조절한다. `Shift + 1`을 다시 누르거나 `Shift + 2`로 조절을 끝낸다.
5. `Shift + 2`는 조절 모드에서 빠져나오거나 상세 시트를 닫고, 단계 목록 → 설정 → 기본 화면 순서로 돌아간다. 기본 화면에서는 포커스 표시를 끝낸다.

Trigger를 놓은 뒤 스틱을 중앙으로 놓으면 이동 입력이 복원된다. 설정이 열려 있어도 Trigger를 누르지 않으면 스틱으로 플레이어를 이동한다. 왼손 Grip은 앱 종료이므로 태블릿에서 뒤로 갈 때는 Y를 사용한다. 오른손 Meta 버튼은 기기의 시스템 메뉴로 유지하며 앱 입력에 연결하지 않는다.

## 머리·몸·손 움직이기

| 키보드·마우스 입력 | 실제 기기에서 대응하는 움직임 |
| --- | --- |
| W / S / A / D | 몸을 앞 / 뒤 / 왼쪽 / 오른쪽으로 이동. 손 조작 모드에서는 선택한 손 이동 |
| Q / E | 몸 또는 선택한 손을 아래 / 위로 이동 |
| 마우스 오른쪽 버튼을 누른 채 마우스 이동 | 고개 또는 선택한 손의 방향 회전 |
| 방향키 | 고개 또는 선택한 손의 방향 회전 |

WASD는 실제 몸·손의 이동을 흉내 낸다. **컨트롤러 스틱으로 이동하려면 Shift + I/K/J/L을 사용한다.**

## 조작 대상 선택

| 입력 | 동작 |
| --- | --- |
| [ / ]를 눌렀다 놓기 | 왼손 / 오른손 위치·회전 조작 선택 |
| [와 ]를 동시에 누르기 | 양손 위치·회전 조작 선택 |
| Tab | 몸 전체를 움직이는 FPS 모드와 손 조작 모드 전환 |
| H | 머리만 움직이는 모드 전환 |
| R | 조작 대상 위치·회전 초기화 |

손 위치를 선택하는 [ / ]는 버튼 입력의 왼손·오른손 선택과 별개다. 왼손 버튼 입력에는 Shift가 필요하다. 시작 시 시점이 바닥에 가까우면 FPS 모드에서 E로 높이를 올린다.
