# 통합 조작법

Quest 컨트롤러와 에디터 XR 시뮬레이터 조작을 정리한다. 공통 입력의 구현은 [XR 리그와 태블릿](xr-setup.md)에 있다.

## 공통 컨트롤러 입력

시뮬레이터에서는 Game 뷰를 클릭한 뒤 키보드 입력을 사용한다. **Shift를 누르면 왼손, 누르지 않으면 오른손 버튼·스틱 입력**이다. 왼손 입력은 버튼 키를 먼저 놓고 Shift를 나중에 놓는다.

| Quest 입력 | 시뮬레이터 입력 | 동작 |
| --- | --- | --- |
| 왼쪽 스틱 | Shift + I / K / J / L | 앞 / 뒤 / 왼쪽 / 오른쪽 이동 |
| 왼손 Trigger + 스틱 | Shift + T를 누른 채 I / K / J / L | 태블릿 항목 이동 |
| 왼손 X | Shift + 1 | 태블릿 항목 선택 |
| 왼손 Y | Shift + 2 | 태블릿 뒤로 가기 |
| 왼손 Menu | Shift + M | 태블릿 설정 열기·닫기 |
| 왼손 Grip | Shift + G | 앱 종료 기능 없음 |
| 오른쪽 스틱 | I / K / J / L | 시점 상 / 하 / 좌 / 우 회전 |
| 오른손 A | 1 | 현재 위치에서 시작 정면 복원 |
| 오른손 B | 2 | 오른손 레이 켜기·끄기 |
| 오른손 Trigger | T | 레이로 가리킨 UI·상호작용 대상 선택 |
| 오른손 Grip 유지 | G 유지 | 물체 잡기. 잡은 물체는 오른손 레이를 따라 이동하며 버튼을 놓으면 해제 |

Grip 또는 G를 먼저 누른 상태에서 오른손 레이를 물체에 맞춰도 잡을 수 있다. 잡은 뒤 오른손의 위치·방향을 바꾸면 물체가 잡기 시작한 거리를 유지하며 따라온다. 오른손 스틱은 물체를 잡은 동안에도 시점을 회전시킨다. 레이를 끄면 잡고 있던 물체가 해제되고 대상 선택도 중단된다. 오른손 Meta 버튼은 기기의 시스템 메뉴다.

## 태블릿

1. 왼손 Trigger를 누르고 스틱을 중앙에 놓아 탐색을 시작한다.
2. Trigger를 유지한 채 스틱으로 항목을 고르고 X로 실행한다. X 선택은 Trigger를 놓은 상태에서도 가능하다.
3. Y로 현재 화면이나 조절 모드를 닫는다. 기본 화면에서는 태블릿 조작을 끝낸다.

Trigger를 누르는 동안 플레이어 이동은 멈춘다. Trigger를 놓은 뒤 스틱도 중앙으로 놓아야 이동이 복원된다. 화면이 열린 상태에서도 Trigger를 누르지 않으면 스틱은 플레이어 이동에 사용된다.

| 항목 | 조작 |
| --- | --- |
| 설정 | Menu로 열고 닫는다. |
| 밝기·음량 | 항목에서 X로 조절을 시작하고 Trigger + 스틱 좌우로 변경한다. X 또는 Y로 조절을 끝낸다. |
| 진동 | 설정 항목을 X로 선택해 켜기·끄기를 전환한다. |
| 단계 이동 | 설정의 단계 목록이나 메인 화면의 단계 항목을 선택한다. 시작 지점이 연결된 단계는 해당 위치로 이동한다. |
| 양피지 열람 | 획득한 양피지를 선택하고 이전·다음·닫기 버튼을 사용한다. Y로도 닫을 수 있다. |
| 양피지 예시 | 특징 맵 예시 페이지에서는 각 맵 버튼으로 표시를 켜고 끈다. |
| 미니맵 | 미니맵을 선택하면 공장 전체 지도와 미수집 양피지 위치가 열린다. 완료 또는 Y로 닫는다. |
| 힌트·이미지 확대·학습 정보 | 해당 항목을 선택하고 완료 또는 Y로 닫는다. |
| 저장 | 밝기·음량·진동과 선택 단계·문서 인덱스를 저장한다. 양피지 수집 여부는 앱 실행 중에만 유지된다. |
| 나가기 | 메인 화면에서 태블릿 조작을 끝낸다. |
| 앱 종료 | 설정에서 앱 종료를 선택한 뒤 확인한다. 취소 또는 Y로 돌아간다. |

에디터 시뮬레이터에서도 실기기와 동일하게 태블릿이 왼손을 따라간다. 탐색 시작·종료 시 태블릿의 위치와 크기는 바뀌지 않는다.

## 오프닝과 튜토리얼

`FactoryIntro`에서 오른손 ray로 시작하기를 가리키고 Trigger를 누르면 악령의 습격과 이야기 애니메이션이 진행된다. 연출이 끝나면 화면이 전환되고 실제 공장 입구로 들어간다.

공장 입구에서 이동·선택·잡기·정면 복원·태블릿의 다섯 페이지 안내를 한 번 표시한다. 공장 배경 위에 `FactoryTutorial` 씬을 Additive로 불러오는 방식이다. 이전/다음/안내 마치기를 Trigger로 선택한다. 고개를 돌리거나 목표 위치에 도착하거나 물체를 놓는 등 수행 미션과 입력 순서 검사는 없다. 안내를 마치면 튜토리얼 씬을 닫고 바닥의 고정 화살표를 표시하므로 이를 따라 첫 방으로 이동한다. 태블릿은 기존 왼손 조작을 그대로 사용한다.

## 공장 탐색

- 정문 앞에서 시작해 바닥의 안내선을 따라 Pixel Lab → Feature Map Lab → Model Design Lab 순서로 직접 이동한다. 현재 허용된 방 안에 들어가면 체험이 시작된다. 안내판에는 `바닥의 안내선을 따라 이동하세요.`만 표시한다.
- 양피지는 가까이 다가가 오른손 Trigger 또는 Grip으로 수집한다. 획득한 문서는 태블릿에서 읽는다.
- 체험 완료 조건을 충족하면 다음 방의 고정 바닥선·화살표를 표시한다. 이동 중 경로 형태는 바뀌지 않는다. 미완료 상태로 나가면 현재 체험으로 돌아가는 길을 안내한다. 물체를 잡은 동안 다음 체험 전환은 기다리며, 목표 방 안에서 놓으면 진행한다.
- 마지막 모델 학습이 정상 완료되어 결과가 표시되면 뒤쪽 출구로 안내한다. 출구에 들어가면 `FactoryEnding`이 시작된다. 학습 실패·취소는 완료로 처리하지 않는다.
- 공용 왼손 스틱 이동 속도는 5m/s다. 벽 통과 방지는 아직 적용하지 않았으며 에디터 FPS 모드의 WASD 몸 이동 속도도 5m/s다.

## CNN 픽셀 관찰과 합성곱

### 픽셀과 RGB 관찰

1. 이미지는 시작부터 원래 크기의 2배로 표시된다. 오른손 Grip으로 필터를 잡아 오른손 레이로 움직이고, 원본 이미지의 관찰할 위치에 놓는다.
2. 더 자세히 보기로 선택 영역을 확인하고, 영역을 직접 꺼내 놓아 RGB 층을 관찰한다.
3. 층을 잡아 벌리거나 같은 픽셀 칸을 가리킨다. RGB 합쳐 보기와 다시 펼치기로 겹침 상태를 바꾼다.
4. 이미지로 돌아간 뒤 다음으로를 선택한다. 이미지 크기와 조작판 위치는 유지된다. 이미지를 Trigger로 선택하고 R/G/B 버튼을 Trigger로 눌러 채널을 비교한다. 필터는 오른손 Grip으로 잡아 오른손 레이로 옮기고 놓아 관찰 영역을 바꾼다.
5. 합성곱 연산 원리 알아보기로 계산 단계에 들어간다.

### 합성곱 계산

- 이미지 꺼내기, 3층 필터 맞추기, R/G/B 층 꺼내기에서 막히면 `자동 맞추고 다음으로` 또는 `자동 꺼내고 다음으로`를 사용한다. 현재 동작만 자동 처리하며 다음 학습 단계를 생략하지 않는다.
- 필터 배치는 보이지 않는 묶음 기준점 대신 각 가중치 층과 같은 색 입력 층의 위치·방향을 비교한다. 겹치거나 앞뒤로 조금 떨어진 배치를 허용하고 성공하면 읽기 위치로 정렬한다.
- 퀴즈의 `정답 보고 다음으로`는 현재 문제만 건너뛰고 계산 결과를 보여 준다. 정답을 직접 맞혔다는 피드백은 표시하지 않는다.
- 이미지 클릭 단계의 `픽셀로 바꾸고 다음으로`는 픽셀 표시를 완료한다. RGB 관찰의 `다음으로`는 이미지 관찰 뒤 다음 단계로 진행한다.
- 3층 필터를 RGB 입력에 맞춰 놓고 대응 관계 확인을 마친다.
- 안내에 따라 R 층을 꺼내고 가중치를 맞춘다. 계속으로 자동 정렬할 수도 있다.
- R 계산은 계산 시작, 다음 줄, 전체 합 버튼으로 진행한다.
- G/B 계산은 해당 채널 층을 직접 꺼내 놓은 뒤, 숫자 블록을 답 칸에 놓거나 숫자 버튼으로 답한다. 잘못 놓은 블록은 원위치로 돌아간다.
- RGB 최종 합을 확인한 뒤 결과 정리 보기를 선택한다. 계산 다시 보기로 계산 학습을 다시 시작하고, 처음부터로 체험을 초기화할 수 있다.

## CNN 특징 맵 체험

| 대상·버튼 | 조작 |
| --- | --- |
| 이전·다음 | 4개 학습 단계 사이를 이동한다. |
| 입력 픽셀 | Trigger로 선택한다. 1~2단계는 필터 위치 선택, 3단계는 수용 영역 강조, 4단계는 흑백 값 변경이다. |
| 필터 | Grip으로 잡아 입력 격자 위에서 이동한다. |
| 필터 바꾸기 | 1~2단계에서 적용 필터를 바꾼다. |
| 자동 이동 | 1~2단계에서 필터의 전체 위치 순회를 시작하거나 멈춘다. |
| 뉴런·특징 맵·층 | Grip으로 잡아 이동한다. Trigger로 선택하거나 잡았다 놓은 대상을 확대·축소 버튼으로 조절한다. |
| 층 손잡이 | Trigger로 해당 층을 펼치거나 접는다. |
| 펼치기 | 층을 펼치거나 접는다. 버튼은 2단계부터 사용한다. |
| 처음 상태 | 입력 값, 방문 기록, 수정 횟수와 배치를 초기화한다. |

물체를 잡은 동안에는 안내 버튼과 확대·축소를 사용할 수 없다. 각 단계는 `다음으로`로 진행한다. 마지막 단계에서 입력을 한 번 이상 변경하거나 `단계 마치기`로 현재 활동을 건너뛴 뒤 물체를 놓으면 다음 방으로 이동할 수 있다. 건너뛰기는 입력 변경 횟수에 포함하지 않는다.

## 모델 제작과 학습

- 아래쪽 단계 버튼으로 조립 → 학습 화면 → 숫자 예측 화면을 하나씩 넘길 수 있다. 이 버튼은 모델을 자동 조립하거나 가짜 학습·예측 결과를 만들지 않는다. 마지막 화면의 `현재 단계 마치기 / 건너뛰기`를 누르면 학습 완료와 별도의 건너뛰기 상태로 출구 안내를 허용한다. 계산 중에는 종료하지 않으며 학습 중지 또는 계산 완료 후 진행한다.
1. 공장에서는 바닥선을 따라 Model Design Lab에 들어간다.
2. 공급대의 블록을 Grip으로 잡아 슬롯에 놓는다. Input·Output 블록은 고정되어 있다.
3. 슬롯 앞 조작기기를 Trigger로 선택해 설정을 연다. `-` / `+`로 숫자를, `<` / `>`로 활성화 함수를 바꾼다. `Done`으로 닫고 `Delete`로 블록을 삭제한다.
4. 학습 시작을 누른다. 학습 중에는 중지 버튼으로 취소를 요청할 수 있다.
5. 학습 결과 화면에서 숫자 샘플을 선택해 예측 결과를 확인한다.

블록 설정은 슬롯에 배치한 뒤 사용할 수 있다. 학습 중에도 블록을 편집할 수 있으며, 결과는 학습 시작 당시 모델을 기준으로 표시된다.

## 엔딩

`FactoryEnding`의 복구 연출 후 개념 복습 화면에서 체험 마무리를 Trigger로 선택하면 완료 화면이 열린다. 처음으로는 오프닝으로 돌아가고, 앱 종료는 실행 중인 앱을 종료한다. 에디터에서 엔딩 패널의 앱 종료 버튼은 안내를 표시한다.

## XR 시뮬레이터의 머리·몸·손 이동

컨트롤러 버튼 입력과 가상 기기의 위치·회전 조작은 별개다. `[ / ]`로 왼손 위치를 선택해도 왼손 버튼 입력에는 Shift가 필요하다.

| 입력 | 동작 |
| --- | --- |
| W / S / A / D | FPS 모드에서는 몸을 앞 / 뒤 / 왼쪽 / 오른쪽으로 이동. 손 조작 모드에서는 선택한 손 이동 |
| Q / E | 몸 또는 선택한 손을 아래 / 위로 이동 |
| 마우스 오른쪽 버튼 + 마우스 이동 | 고개 또는 선택한 손 회전 |
| 방향키 | 고개 또는 선택한 손 회전 |
| [ / ]를 눌렀다 놓기 | 왼손 / 오른손 위치·회전 조작 선택 |
| [와 ]를 함께 누르기 | 양손 위치·회전 조작 선택 |
| Tab | FPS 모드와 손 조작 모드 전환 |
| H | 머리만 조작하는 모드 전환 |
| R | 양손 컨트롤러 위치·회전을 현재 머리 기준으로 초기화 |

WASD는 몸의 이동을 흉내 낸다. 왼쪽 스틱 이동을 직접 조작하려면 Shift + I/K/J/L을 사용한다. 시작 시 시점이 바닥에 가까우면 FPS 모드에서 E로 높이를 올린다.

Quest Link를 사용할 때는 PC/Standalone의 `Initialize XR on Startup`을 켜고, `Project Settings > XR Plug-in Management > XR Interaction Toolkit`의 `Use XR Interaction Simulator in scenes`를 끈다. 키보드·마우스 시뮬레이터로 돌아올 때는 반대로 설정한다.
