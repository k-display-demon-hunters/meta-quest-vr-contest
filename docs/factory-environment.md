# 폐공장 환경 씬

`client/Assets/Scenes/FactoryEnvironment.unity`는 공장 **공간만** 담은 독립 씬이다. XR 리그·태블릿·교육 입력·학습 로직·씬 전환 코드는 포함하지 않는다. 기존 `FactoryIntro`, `QuestMain`, `FactoryEnding` 및 교육 씬과의 연결은 후속 통합 작업에서 결정한다. Unity 1 unit은 1 m로 사용한다.

## 배치와 동선

```text
정문·하역장 (-Z)
  → 보안/튜토리얼 준비 공간
  → 중앙 생산 복도
      ├─ 서쪽 원본 검사실          (x -19~-3, z -1~12)
      ├─ 서쪽 특징 추출실          (x -19~-3, z 14~28)
      ├─ 동쪽 모델 조립실          (x 3~21, z 10~28)
      └─ 동쪽 출하 검사 구역       (x 3~21, z 29~40)
```

오프닝에서 공장으로 들어오는 위치는 `(0, 0, -20)`, 출하 구역에서 엔딩으로 이어질 위치는 `(12.5, 0, 40)`이다. 중앙 복도와 각 실 사이에는 약 3.4 m의 열린 출입구를 두었다. 실제 전환·잠금·진행 조건은 구현하지 않았다.

## 씬 계층

`Factory Environment` 루트 아래에 `00` 정문/하역장, `01` 보안 구역, `02` 중앙 복도, `03` 원본 검사실, `04` 특징 추출실, `05` 모델 조립실, `06` 출하 구역, `07` 조명, `08` 콘텐츠 연결 기준점이 있다. 팀원이 작업할 때는 해당 실의 `CONTENT ZONE` 빈 Transform을 기준으로 교육 장치를 배치할 수 있다. 중심부의 대략 6 × 6 m는 콘텐츠용으로 비워 두고 큰 고정 설비는 가장자리로 배치했다.

씬 전용 URP 재질은 `Assets/Materials/FactoryEnvironment/`, 표면 이미지와 노멀·금속/매끄러움 맵은 `Assets/Textures/FactoryEnvironment/`에 있다. 마모된 콘크리트, 벗겨진 도장 강판, 산화된 철, 고무, 주의 도색, 철제 그레이팅을 사용한다. 에셋의 `.meta`를 이동·재생성하지 않아야 씬 참조가 유지된다.

## 방 입구 간판

중앙 생산 복도에서 보이는 세 출입구의 상부 벽에 약 3.7 × 1.1 m 크기의 낡은 금속 프레임 간판을 배치했다. 문 아래 통행 높이 3 m는 유지한다. 간판 표면은 씬 전용 텍스처와 URP Unlit 재질로 구성해 어두운 복도에서도 글자를 읽을 수 있다.

- 단비 / 서쪽 아래 원본 검사실: `Convolution Room`
- 다연 / 동쪽 모델 조립실: `MLP Room`
- 하율 / 서쪽 위 특징 추출실: `CNN Room`

## 조명과 편집

고정된 등기구 표현, 8개의 그림자 없는 점광원, 무너진 지붕 틈으로 들어오는 차가운 방향광을 배치했다. 방향광은 부드러운 실시간 그림자를 만든다. 구조물은 정적 배치로 표시했으며, 라이트맵은 아직 굽지 않았다. 상부 철판과 트러스는 일부 무너진 지붕 형태로 만들었다. Scene View에서 실 내부를 편집할 때 해당 공간의 지붕 오브젝트를 임시로 숨기면 된다.

주요 바닥과 벽 외에 보안 설비, 실별 고정 기계·보관함, 조립실 부품 랙, 출하 컨베이어와 상자에도 Box Collider를 두었다. 출하 컨베이어와 상자는 동쪽 벽 쪽에 배치해 `(12.5, 0, 40)` 출구 앞 통로를 비웠다. 특징 추출실의 관찰창은 반투명 재질이다.

씬은 XR 리그와 카메라가 없는 환경 전용 씬이다. 단독 Play를 위한 입력·카메라를 새로 추가하지 말고, 팀의 씬 연결 작업에서 기존 공용 `XRPlayerRig`를 사용한다. 이 씬을 빌드 씬 목록에 추가하거나 기존 씬을 수정하지 않았다.

사용자 허가에 따라 Unity 6000.3.24f1에서 씬을 열어 장면 배치와 재질·조명을 확인했다. 수정 후 재가져오기를 마친 Console의 오류와 경고는 모두 0건이었다. Play, 라이트 베이크, 자동 테스트, 빌드 및 Quest 성능 측정은 수행하지 않았다.
