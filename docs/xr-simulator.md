# 통합 조작법

Quest 컨트롤러와 에디터 XR 시뮬레이터 조작을 정리한다. 공통 입력의 구현은 [XR 리그와 태블릿](xr-setup.md)에 있다.

## 공통 컨트롤러 입력

시뮬레이터에서는 Game 뷰를 클릭한 뒤 키보드 입력을 사용한다. **Shift를 누르면 왼손, 누르지 않으면 오른손 버튼·조이스틱 입력**이다. 왼손 입력은 버튼 키를 먼저 놓고 Shift를 나중에 놓는다.

| Quest 입력 | 시뮬레이터 입력 | 동작 |
| --- | --- | --- |
| 왼쪽 조이스틱 | Shift + I / K / J / L | 앞 / 뒤 / 왼쪽 / 오른쪽 이동 |
| 왼손 Trigger + 조이스틱 | Shift + T를 누른 채 I / K / J / L | 태블릿 항목 이동 |
| 왼손 X | Shift + 1 | 태블릿 항목 선택 |
| 왼손 Y | Shift + 2 | 태블릿 뒤로 가기 |
| 왼손 Menu | Shift + M | 태블릿 설정 열기·닫기 |
| 왼손 Grip | Shift + G | 앱 종료 기능 없음 |
| 오른쪽 조이스틱 | I / K / J / L | 시점 상 / 하 / 좌 / 우 회전 |
| 오른손 A | 1 | 현재 위치에서 시작 정면 복원 |
| 오른손 B | 2 | 오른손 레이 켜기·끄기 |
| 오른손 Trigger | T | 레이로 가리킨 UI·상호작용 대상 선택 |
| 오른손 Grip 유지 | G 유지 | 물체 잡기. 잡은 물체는 오른손 레이를 따라 이동하며 버튼을 놓으면 해제 |

Grip 또는 G를 먼저 누른 상태에서 오른손 레이를 물체에 맞춰도 잡을 수 있다. 잡은 뒤 오른손의 위치·방향을 바꾸면 물체가 잡기 시작한 거리를 유지하며 따라온다. 오른손 조이스틱은 물체를 잡은 동안에도 시점을 회전시킨다. 레이를 끄면 잡고 있던 물체가 해제되고 대상 선택도 중단된다. 오른손 Meta 버튼은 기기의 시스템 메뉴다.

## 태블릿

1. 왼손 Trigger를 누르고 조이스틱을 중앙에 놓아 탐색을 시작한다.
2. Trigger를 유지한 채 조이스틱으로 항목을 고르고 X로 실행한다. X 선택은 Trigger를 놓은 상태에서도 가능하다.
3. Y로 현재 화면이나 조절 모드를 닫는다. 기본 화면에서는 태블릿 조작을 끝낸다.

Trigger를 누르는 동안 플레이어 이동은 멈춘다. Trigger를 놓은 뒤 조이스틱도 중앙으로 놓아야 이동이 복원된다. 화면이 열린 상태에서도 Trigger를 누르지 않으면 조이스틱은 플레이어 이동에 사용된다.

| 항목 | 조작 |
| --- | --- |
| 설정 | Menu로 열고 닫는다. |
| 밝기·음량 | 항목에서 X로 조절을 시작하고 Trigger + 조이스틱 좌우로 변경한다. X 또는 Y로 조절을 끝낸다. |
| 진동 | 설정 항목을 X로 선택해 켜기·끄기를 전환한다. |
| 단계 이동 | 학습 단계 앱에서 픽셀·합성곱·특징 맵·모델 제작 중 하나를 선택하면 해당 체험으로 텔레포트한다. 재방문은 처음부터 시작하며 완료 기록은 유지한다. 로딩 중에는 선택할 수 없다. |
| 양피지 열람 | 공장에서 양피지를 클릭하면 즉시 수집되어 태블릿에 보관되고 공용 확대 창이 열린다. 보관된 양피지는 양피지 앱의 수집 목록에서 다시 선택해 열람한다. 오른손 레이로 이전·다음·완료·닫기 버튼을 가리키고 Trigger로 누른다. 열람 중에는 왼쪽 스틱 이동과 태블릿 입력이 차단된다. |
| 양피지 예시 | 모든 페이지에 지정된 삽화를 항상 표시한다. 특징 맵 세 개도 고정 표시하며 조작 버튼은 없다. |
| 미니맵 | 지도 앱을 선택하면 오른쪽에 사용자 중심의 주변 지도와 방향·미수집 양피지를 표시한다. 이동하면 지도도 따라간다. |
| 저장 | 밝기·음량·진동과 선택 문서 인덱스를 저장한다. 학습 진행률은 저장하지 않는다. 양피지 수집 여부는 앱 실행 중에만 유지된다. |
| 진행률 | 픽셀·합성곱·특징 맵·모델 제작을 완료할 때마다 25% 증가한다. 양피지 수집은 별도다. |
| 앱 종료 | 설정에서 앱 종료를 선택한 뒤 확인한다. 취소 또는 Y로 돌아간다. |

에디터 시뮬레이터에서도 실기기와 동일하게 태블릿이 왼손을 따라간다. 탐색 시작·종료 시 태블릿의 위치와 크기는 바뀌지 않는다.

## 공장 진입과 튜토리얼

FactoryIntro에서 GAME START를 오른손 레이와 Trigger로 선택하면 18초 습격 연출과 경고창·진동을 표시한다. 복구 요청의 [공장 수리하기]를 선택하거나 오른손 A를 누르면 문이 열린다. 왼쪽 조이스틱을 앞으로 밀어 빛나는 바닥 경로를 따라 직접 문을 통과하면 공장 내부로 전환된다.

현재 공간은 FactoryEnvironment를 직접 실행하면 정문 앞에서 시작한다. 청록색 안내선을 따라 튜토리얼실에 들어가면 입구 셔터가 닫히고 11개 조작 안내 화면과 최종 미션 안내를 표시한다. 이전/다음/미션 시작과 최종 확인을 Trigger로 선택한다. 건너뛰기 버튼과 실제 동작 수행 판정은 없다. 안내를 마치고 다음 체험이 준비되면 ROOM #1로 가는 출구가 열린다.

기존 FactoryIntro·FactoryEnding 연출 파일은 유지되어 있다. 정문·후문용 새 연출은 포함하지 않으며, 모델 제작을 완료하고 후문에 들어가면 기존 FactoryEnding을 실행한다.

## 공장 탐색

- 정문 → 튜토리얼실 → ROOM #1 Pixel Lab → ROOM #2 Feature Map Lab → ROOM #3 Model Design Lab → 후문 순서로 연결 복도를 직접 이동한다.
- 방 안으로 들어오면 입구 셔터가 내려가고 안내선이 사라진다. 체험 중에는 입구와 출구가 닫혀 있으며, 기존 완료 조건을 충족해야 출구와 다음 방 입구가 열린다.
- 다음 콘텐츠가 준비되는 동안에는 현재 방에서 기다린다. 준비가 끝나면 다음 방까지의 청록색 바닥 화살표가 나타난다. 다음 방 진입 후 이전 체험을 정리한다.
- 특징 맵의 기존 건너뛰기 완료 판정은 유지한다. 모델 학습 실패·취소는 완료로 인정하지 않는다.
양피지는 클릭 즉시 수집하고 열람창을 연다. 문별 배분과 위치 안내는 ParchmentLesson.Location을 사용한다. ROOM #1~#3 입구 및 ROOM #1 내부문은 기존 진행 조건에 해당 위치의 전체 수집 조건을 추가한다. 출구는 기존 조건을 유지한다. 픽셀 입구는 05, 합성곱 입구는 01, 특징 맵 입구는 02, 모델 설계 입구는 03·04를 수집한다. 자세한 연결은 [공용 양피지](parchment.md)를 따른다.
- 후문에 들어가면 기존 FactoryEnding의 복구 연출과 완료 화면으로 전환한다.
- 왼손 스틱 이동은 기존 XRPlayerRig의 CharacterController와 벽·셔터 Collider를 사용한다. 속도는 5m/s다. 에디터 FPS 모드의 WASD는 XR 시뮬레이터의 몸 추적 위치를 직접 바꾸므로 스틱 충돌 동작과 같지 않다. 스틱 이동 입력은 Shift + I/K/J/L로 조작한다.

## CNN 픽셀 관찰과 합성곱

### 픽셀과 RGB 관찰

1. 공장 ROOM #1의 오른쪽 1-1 스크린 공간에서 푸른 바닥 경계 안의 돋보기를 Grip으로 잡아 이미지 위에 놓는다.
2. 돋보기 속 픽셀을 관찰하고 짧은 안내 페이지를 읽는다. 픽셀 확대하기를 누르면 이미지와 돋보기가 왼쪽으로 작아지며 이동하고, 선택한 3×3 영역의 RGB 세 층이 옆에 펼쳐진다.
3. 픽셀·RGB 안내 후 첫 공간에서 R·G를 순서대로 연습한다. Grip으로 색 층을 꺼내고 가중치판을 빛나는 테두리에 맞춘다. 각 곱은 오른쪽 계산판에 기록된다. R·G 학습의 다음 공간으로를 누르고 입구 양피지를 수집하면 내부 셔터가 열린다. 안내선을 따라 왼쪽 1-2 공간으로 이동해 B 퀴즈를 풀면 된다. CNNPixelLab 단독 실행에서는 같은 위치에서 씬을 교체한다.
4. 처음으로는 선택과 관찰·완료 상태를 초기화한다.

### 합성곱 계산

- 첫 공간은 R·G 학습, 내부 문을 지난 두 번째 공간은 B 퀴즈다. 관찰 숫자는 0~255, 계산은 명시된 연습용 값 0~3을 사용한다.
- RGB 층을 Grip으로 꺼내고, 화살표가 가리키는 가중치판을 잡아 빛나는 테두리에 놓는다. 가까이 놓으면 정렬된다. 막히면 `자동 배치`로 현재 물리 조작만 완료할 수 있다.
- R·G는 각 곱셈 애니메이션을 보고 계산판에 쌓이는 식을 읽는다. 세 항마다 `다음 줄`, 마지막에 `합 확인`을 눌러 진행한다.
- B는 숫자 블록을 답 칸에 놓거나 큰 숫자 버튼을 눌러 답한다. 오답은 다시 풀며 정답 건너뛰기는 없다.
- 정답 후 `결과 확인`을 누르면 학습이 완료된다. 공장에서는 `학습 마치기`가 완료 상태를 유지하며 표시를 닫는다. 단독 실행의 `다른 영역 보기`는 관찰 씬으로 돌아가 선택 좌표를 복원한다.

## CNN 특징 맵 체험

양피지 3에서는 필터 A/B 실행 버튼을 레이로 가리키고 Trigger/T로 실행한다. 결과 설명 팝업은 확인으로 닫는다. 두 필터 실행과 설명 확인을 마치고 완료를 누르면 필터 비교 체험이 사라지고 컬러 피처맵 탐색이 시작된다.

피처맵 탐색에서는 컬러 입력과 2·3·5장의 피쳐맵이 표시된다.

| 대상·입력 | 동작 |
| --- | --- |
| 맵 테두리 + Grip/G 유지 | 맵을 꺼내 옆으로 이동. 놓으면 그 자리에 남는다. |
| 맵·칸 + Trigger/T | 앞 채널의 계산을 더해 한 피쳐맵을 만드는 설명 창 표시. 확인으로 닫는다. |
| 입력 픽셀 + Trigger/T | 뒤쪽 세 층에서 가중치로 연결되는 칸을 노란색으로 강조. |
| 층 손잡이 + Trigger/T, 또는 펼치기 버튼 | 층의 여러 맵을 펼쳐 본다. |
| 대상 선택 후 확대·축소 | 맵·층·픽셀 크기 변경. 먼저 잡은 물체를 놓는다. |
| 원위치 | 위치·크기·강조 복원과 계산 창 닫기. |
| 완료 | 양피지 4 체험 완료. |

자세한 계산·표시 기준은 [CNN 특징 맵 구현](cnn-feature-map-explorer.md)을 참고한다.

## 양피지 5: 활성화 함수

1. 양피지 4에서 완료를 누르면 기존 화면이 사라지고 ReLU 체험이 시작된다.
2. ReLU 체험 안내를 확인한다.
3. **ReLU 적용**을 누른다. 왼쪽은 적용 전, 오른쪽은 적용 후다. 파란 음수 칸은 회색 0이 되고 주황색 양수 칸은 그대로 남는다.
4. 결과 설명을 확인한 뒤 맵의 칸을 Trigger/Grip으로 선택한다. 같은 위치의 전후 숫자와 테두리가 함께 표시된다.
5. **맵 바꾸기**로 빨강 검출·세로 경계 피쳐맵을 비교하거나 **다시 실행**으로 변환을 다시 볼 수 있다.
6. **완료 → 확인**을 누르면 다음 방으로 진행할 수 있다.

이 체험에서는 한 맵에 ReLU를 적용하며, 원래 양피지 4의 계산값과 맵 크기는 변경하지 않는다.

## 모델 제작과 학습

- 아래쪽 단계 버튼으로 조립 → 학습 화면 → 숫자 예측 화면을 하나씩 넘길 수 있다. 이 버튼은 모델을 자동 조립하거나 가짜 학습·예측 결과를 만들지 않는다. 마지막 화면의 `현재 단계 마치기 / 건너뛰기`를 누르면 학습 완료와 별도의 건너뛰기 상태로 출구 안내를 허용한다. 계산 중에는 종료하지 않으며 학습 중지 또는 계산 완료 후 진행한다.
1. 공장에서는 바닥선을 따라 Model Design Lab에 들어간다.
2. 공급대의 블록을 Grip으로 잡아 슬롯에 놓는다. Input·Output 블록은 고정되어 있다.
3. 슬롯 앞 조작기기를 Trigger로 선택해 설정을 연다. `-` / `+`로 숫자를, `<` / `>`로 활성화 함수를 바꾼다. `Done`으로 닫고 `Delete`로 블록을 삭제한다.
4. 학습 시작을 누른다. 학습 중에는 중지 버튼으로 취소를 요청할 수 있다.
5. 학습 결과 화면에서 숫자 샘플을 선택해 예측 결과를 확인한다.

블록 설정은 슬롯에 배치한 뒤 사용할 수 있다. 학습 중에도 블록을 편집할 수 있으며, 결과는 학습 시작 당시 모델을 기준으로 표시된다.

## 엔딩

`FactoryEnding`의 23초 복구 연출이 끝나면 축하 메시지와 완료 화면이 열린다. 처음으로는 오프닝으로 돌아가고, 앱 종료는 실행 중인 앱을 종료한다. 에디터에서 엔딩 패널의 앱 종료 버튼은 안내를 표시한다.

## XR 시뮬레이터의 머리·몸·손 이동

컨트롤러 버튼 입력과 가상 기기의 위치·회전 조작은 별개다. `[ / ]`로 왼손 위치를 선택해도 왼손 버튼 입력에는 Shift가 필요하다.

| 입력 | 동작 |
| --- | --- |
| W / S / A / D | FPS 모드에서는 몸을 앞 / 뒤 / 왼쪽 / 오른쪽으로 이동. 손 조작 모드에서는 선택한 손 이동 |
| Q / E | 몸 또는 선택한 손을 아래 / 위로 이동 |
| 마우스 오른쪽 버튼 + 마우스 이동 | 고개 또는 선택한 손 회전 |
| 방향키 | 고개 또는 선택한 손 회전 |
| [ / ]를 눌렀다 놓기 | 왼손 / 오른손 위치·회전 조작 선택 |
| [와 ]를 함께 누르기 | 양손 위치·회전 조작 선택 |
| Tab | FPS 모드와 손 조작 모드 전환 |
| H | 머리만 조작하는 모드 전환 |
| R | 양손 컨트롤러 위치·회전을 현재 머리 기준으로 초기화 |

WASD는 몸의 이동을 흉내 낸다. 왼쪽 조이스틱 이동을 직접 조작하려면 Shift + I/K/J/L을 사용한다. 시작 시 시점이 바닥에 가까우면 FPS 모드에서 E로 높이를 올린다.

Quest Link를 사용할 때는 PC/Standalone의 `Initialize XR on Startup`을 켜고, `Project Settings > XR Plug-in Management > XR Interaction Toolkit`의 `Use XR Interaction Simulator in scenes`를 끈다. 키보드·마우스 시뮬레이터로 돌아올 때는 반대로 설정한다.
