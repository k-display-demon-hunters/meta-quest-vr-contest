# CNN Feature Map VR Exploration

## 위치

- 브랜치: `feature/3d-feature-map-interaction`
- 씬: `client/Assets/Scenes/FeatureMapLab.unity`
- 콘텐츠 프리팹: `client/Assets/Prefabs/FeatureMaps/FeatureMapWorkspace.prefab`
- 코드: `client/Assets/Scripts/FeatureMaps/`

기존 client 프로젝트와 XRPlayerRig를 그대로 사용한다. 별도 Unity 프로젝트·복사본·빌드는 만들지 않는다. 기존 QuestMain과 시작 씬·Build Settings는 변경하지 않는다.

## 화면

텍스트, 설명, 버튼과 별도의 아래쪽 확대 전시는 없다. 입력 픽셀 이미지 → 입체 뉴런으로 구성된 은닉층 3개 → 두 출력 막대를 배치한다. 은닉층 채널 수는 2, 3, 5이다. 각 feature map은 작은 3D 구체 64개가 8×8 격자로 떠 있는 구조다. 총 640개 입체 은닉 뉴런과 입력 픽셀 타일 64개가 있다. CNN의 2D 공간·채널 구조를 3D로 시각화한 것이며 3D convolution으로 변경하지 않는다.

처음에는 입체 뉴런으로 구성된 map들이 앞뒤로 겹친 상태다. 채널 사이에는 0.14m 간격을 두고 각 구체의 직경은 기본 0.048m이다. map의 안쪽은 불투명 판 없이 열린 구조여서 옆과 뒤에서도 구체와 간격을 볼 수 있다. map 테두리를 잡아 꺼내면 해당 뉴런 격자를 가까이에서 볼 수 있다. 판 아래 짧은 손잡이는 은닉층 전체를 잡는 부분이다. map이나 묶음을 회전·확대하고 층을 펼쳐 비교할 수 있다. 꺼낸 판은 자동 펼침에서 제외해 사용자가 둔 위치를 보존한다. R/오른쪽 스틱 클릭으로 모두 복귀한다.

은닉 뉴런은 처음부터 개별 MeshRenderer와 SphereCollider를 가진 구체로 표시한다. URP Lit 재질의 조명 반사로 곡면이 보이고, 영향을 받는 뉴런은 밝은 황금색과 emission으로 강조한다. map을 꺼내거나 노드를 따로 움직여도 뉴런은 계속 표시한다. 전체 복귀 시에도 Renderer를 끄지 않는다. 입력은 원본 이미지 값을 표현하는 평면 픽셀 타일을 유지한다. 은닉층의 평면 backing과 격자 텍스처 생성 코드는 제거했다. 모든 뉴런을 실제 메시로 표시하므로 이전 텍스처 표현보다 렌더링 비용이 늘어나며, Quest 성능은 실행 검증하지 않았다.

기존 태블릿 문자는 이 콘텐츠 씬에서만 잠시 숨기고 씬을 나갈 때 이전 활성 상태로 복원한다. 태블릿 프리팹·기존 입력 코드는 수정하지 않는다.

## 픽셀 영향 강조

입력 픽셀을 선택하면 그 입력을 수용 영역에 포함하는 은닉층 셀을 모두 밝게 표시한다. 현재 활성값 크기나 예측 중요도 대신 CNN 구조상의 receptive field 포함 관계를 표시한다. 현재 고정 커널의 값이 0이어도 수용 영역에 포함하면 강조한다.

각 층은 3×3, stride 1, same zero padding, ReLU이며 다음 층의 모든 출력 채널이 이전 층의 모든 입력 채널을 본다. 중앙 픽셀을 선택하면 영향을 받는 공간 범위는 3×3 → 5×5 → 7×7로 확장되고, 경계에서는 유효 격자 크기로 잘린다. 이동·회전·확대·펼침은 채널·행·열을 바꾸지 않으므로 강조 위치의 의미가 유지된다.

입력은 readable 8×8 `Assets/FeatureMaps/Images/InputPixels.png`다. 고정 교육용 경계/평균 필터로 실제 합성곱을 계산한다. 마지막 출력은 전역 평균과 고정 가중치의 2-way softmax를 막대 높이로 표현한다. 학습된 고양이·강아지 분류 모델이나 서버 추론 결과가 아니며 정확도·클래스 이름을 표시하지 않는다. 모델 JSON과 서버 통신에는 연결하지 않는다.

## Quest 조작

- 입력 픽셀: 오른손 레이로 가리키고 Trigger로 선택한다. Grip으로 셀을 잡아 꺼내도 선택된다.
- 셀 또는 map: 셀/판 테두리에 오른손 레이를 대고 Grip을 유지한 채 이동한다. 컨트롤러를 돌리면 물체도 회전한다.
- 은닉층 전체: 판 아래 손잡이를 Grip으로 잡는다.
- 확대/축소: 잡은 상태에서 A를 유지하면 확대, B를 유지하면 축소한다. 최초 크기 대비 0.4~4배 범위다.
- 펼치기/접기: 층 아래 손잡이를 Grip으로 잡은 채 Trigger를 한 번 누른다.
- 잡은 물체의 거리 조절은 기존 오른쪽 스틱 상호작용을 유지한다.
- 전체 복귀: 아무것도 잡지 않은 상태에서 오른쪽 스틱을 클릭한다. 강조도 해제한다.

왼손은 기존 태블릿/이동 역할을 유지한다. 양손 동시 잡기나 손 추적을 추가하지 않는다.

## PC 대체 조작

- 왼쪽 클릭: 입력 픽셀 선택. 누른 채 드래그하면 셀/map/층 이동.
- map은 테두리, 은닉층은 아래 손잡이를 드래그한다.
- 드래그 중 휠: 깊이 조절.
- Alt + 드래그: 잡은 물체 회전.
- Shift + 휠: 가리키거나 잡은 물체 확대/축소.
- 층 손잡이를 가리킨 상태에서 Space: 펼치기/접기.
- R: 전체 위치·회전·크기와 격자 셀 복귀, 선택 강조 해제.
- 시선 이동은 기존 XR 시뮬레이터의 오른쪽 마우스 버튼을 유지한다. 처음 눈높이가 바닥이면 E로 올린다.

마우스와 VR가 같은 물체 또는 그 상위·하위 물체를 동시에 잡는 것은 선택 필터로 막는다. 복귀는 물체가 잡힌 동안 실행하지 않는다. 사용자가 움직인 위치는 현재 세션에서만 유지된다.

## 소스 역할

- FeatureMapScene: 입력 선택, 데이터·강조 갱신, VR 크기 조작, 전체 복귀.
- FeatureMapExampleData: 3개 합성곱층과 수용 영역 포함 관계.
- FeatureMapPanel: 입체 map 묶음과 꺼내기 상태.
- FeatureMapLayer: 채널 판 펼치기·접기.
- FeatureMapNode: 항상 표시되는 입체 뉴런의 색·발광과 입력 픽셀 선택.
- FeatureMapGrabTarget: 셀/map/층 잡기·회전·크기·복귀와 XR 선택 필터.
- FeatureMapMouseDrag: PC 대체 조작.

이전 FeatureMapAction과 글씨·버튼·연결선 생성 코드, 사용하지 않는 구체 데모 재질은 제거했다.
